Getting Started

Installation
git clone https://github.com/mittalayushh/nextauvserver.git
cd nextAUV

Environment Setup

Create .env files for frontend and backend with the following:

DATABASE_URL=
JWT_SECRET=

Run Development Server

cd server
npm install
node index.js
